A creative digital portfolio combining modern design, AI-assisted media creation, and web development technologies.

## Personal Brand
- **Name:** Kamaleshwari S
- **Role:** Creative Digital Professional | AI Enthusiast | Aspiring Developer
- **Positioning:** Blending digital creativity, AI-powered tools, and programming fundamentals to build modern digital experiences.

---

## Tech Stack
- **Framework:** React 19 + Vite 8
- **Language:** JavaScript (ES Modules)
- **Styling:** Tailwind CSS v4 + Vanilla CSS Design System
- **Icons & Graphics:** Handcrafted Accessible SVGs & Futuristic Glassmorphism Components

---

## Project Structure
```
src/
├── components/
│   ├── Navbar.jsx       # Sticky glassmorphic navbar with active scroll tracking
│   ├── Hero.jsx         # Futuristic Creative AI hero section with abstract visual matrix
│   ├── About.jsx        # Story, philosophy, and 4 visual highlight cards
│   ├── Education.jsx    # Interactive academic timeline
│   ├── Skills.jsx       # Programming & digital skills with interactive category filters
│   ├── Services.jsx     # 9 core creative & digital service cards
│   ├── Experience.jsx   # Current role at VJ Educational Hub & selected project showcase
│   ├── Portfolio.jsx    # Filterable portfolio gallery with category tabs
│   └── Contact.jsx      # Contact details, status indicators, and interactive form
├── App.jsx              # Main application layout and layout orchestration
├── main.jsx             # React DOM entry mount point
└── index.css            # Tailwind CSS v4 import, design system tokens, and keyframe animations
```

---

## Development & Build Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Lint codebase (oxlint)
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
